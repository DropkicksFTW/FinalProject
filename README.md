# FinalProject

Credit: ChatGPT/Google Gemini used for rough template and learning. Arduino.cc and google were also referenced during development.


Delivered Features

    Random sequence generation.

    Button input detection.

    LED and sound feedback.

    The program uses arrays to store button inputs and utilizes save states for game memory.

    The game utilizes random variables for buttons, so each game is unique.

Undelivered Features

    Due to time and hardware constraints, the maximum number of players was reduced from 4 to 3. Adding more players would require multiplexing inputs, and I did not have time to implement it.
